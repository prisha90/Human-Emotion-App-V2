# Phase 1 — Data Quality Improvements

## 1. Face Validation Before Prediction

### Problem

Currently any image can be uploaded.

Examples:

* Empty image
* Landscape
* Multiple people
* Cartoon
* Pet image

The model will still attempt a prediction.

### Improvement

Add face detection before inference.

Process:

1. Detect face
2. If no face found:

   * Show error message
3. If multiple faces:

   * Ask user to select one
4. Crop face automatically

### Expected Benefit

Cleaner custom dataset and better retraining quality.

---

## 2. Blur Detection

### Problem

Users may upload blurry images.

These become noisy training samples.

### Improvement

Use Laplacian Variance:

```python
variance = cv2.Laplacian(
    gray,
    cv2.CV_64F
).var()
```

Reject images below threshold.

### Expected Benefit

Higher quality custom dataset.

---

## 3. Duplicate Image Detection

### Problem

Users can repeatedly upload the same image.

### Improvement

Store image hashes.

Example:

```python
hashlib.md5(image)
```

Reject duplicates.

### Expected Benefit

Prevent dataset pollution.

---

## 4. Automatic Dataset Statistics Dashboard

Generate:

* Total samples
* Samples per emotion
* Feedback count
* Correct predictions
* Incorrect predictions

Display in admin dashboard.

### Expected Benefit

Better monitoring of dataset growth.

# Phase 2 — Better Learning System

## 5. Confidence-Based Learning

Current weighting:

* Wrong prediction = +2
* Webcam = +1
* Low confidence = +1

### Improvement

Use dynamic weighting:

```text
Confidence < 40% → Weight 5
Confidence < 50% → Weight 4
Confidence < 60% → Weight 3
Confidence < 70% → Weight 2
Else → Weight 1
```

### Expected Benefit

Model learns most from uncertain samples.

---

## 6. Hard Example Mining

Store difficult samples separately.

Example:

```text
hard_examples/
```

Criteria:

* Wrong prediction
* Confidence < 50%

Retraining oversamples these images.

### Expected Benefit

Faster accuracy improvement.

---

## 7. Active Learning

Only request feedback when confidence is low.

Example:

```text
Confidence > 90%
No feedback request

Confidence < 70%
Ask user
```

### Expected Benefit

Less user effort.

More valuable labels.
